Cómo funciona

Tres pasos sencillos

1

La pantalla escanea

Las opciones se iluminan una a una con un temporizador. Nada necesita ser apuntado ni pulsado con precisión — la pantalla hace todo el trabajo.

2

Una sola señal selecciona

La cámara vigila un gesto de los ojos, o un cambio facial (como cejas levantadas, o la boca hacia abajo). Lo que esté resaltado en ese momento queda elegido.

3

Las palabras se convierten en habla

Elija una palabra predicha o deletree en el teclado. BlinkTalk aprende las palabras que el usuario usa de verdad — y pronuncia la frase terminada en voz alta.

Características

Diseñado en torno a una sola señal fiable

🎭

Funciona con un gesto simple

La cámara puede entrenarse para detectar el gesto exacto que el usuario puede hacer — una mirada hacia arriba, un parpadeo, una sonrisa, cejas levantadas, cualquier gesto repetible.

🧠

Aprende mientras habla

Cada conversación mejora las predicciones, para que las palabras que el usuario usa de verdad aparezcan primero.

🔊

Habla en voz alta

Las frases terminadas se pronuncian en voz alta, para que el usuario participe en la conversación con naturalidad, cara a cara.

Preguntas

Preguntas frecuentes

¿BlinkTalk es realmente gratis?

Sí. BlinkTalk es gratis y de código abierto — sin anuncios, sin suscripciones, sin costes ocultos. Fue escrito para un amigo con síndrome de enclaustramiento y se ofrece gratuitamente para que cualquiera que lo necesite pueda usarlo.

¿Para quién es BlinkTalk?

Es para personas con síndrome de enclaustramiento u otras afecciones que no pueden usar el tacto, un teclado ni su voz — y para los familiares, cuidadores y terapeutas que les ayudan a comunicarse.

¿Qué necesitamos para empezar?

Un ordenador con Windows o una tableta o teléfono Android. El usuario se comunica con la señal que pueda repetir — un gesto de los ojos o facial — mientras la cámara del dispositivo se entrena para detectar el gesto, o un asistente toca la pantalla, hace clic con el ratón o pulsa la barra espaciadora de un teclado físico.

¿Puede el usuario usarlo por su cuenta?

Sí. Una vez que la cámara se ha entrenado con su gesto, un gesto de los ojos o facial basta para seleccionar. Un asistente solo se necesita para el proceso de configuración cuando la aplicación se inicia.
